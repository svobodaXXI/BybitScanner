## Наблюдения

1. **Ложных поздних срабатываний нет ни у одного кандидата** (`late = 0`); верхняя граница precision везде 1.0.
   Вся неопределённость — в near-miss.
2. **33 из 34 уникальных near-miss событий позже подтверждаются реальным 1m-касанием** (медиана — через 10 мин,
   разброс 1–761 мин); только одно (1000LUNCUSDT, 2026-09-20 16:15) не коснулось линии за 24 ч. То есть допуск в
   основном **сдвигает ретест раньше**, а не ловит отскоки без касания; по правилу 7 это означает более раннее
   закрытие остатка — вопрос владельца, а не статистики касаний.
3. **FN при k = 0 (6 из 62)** — наклонные линии, где 5m-касание неоднозначно по времени (`RETEST_UNPROVEN`), а 1m
   доказывает касание. Допуск не устраняет их монотонно: при k > 0 неоднозначная зона может наступить раньше
   (FN 7 у 7×0.05 и 14×0.15). Разрешение 5m через 1m (плановый вариант 5m→1m) убрало бы этот класс FN без допуска.
4. **Устойчивость по периоду ATR:** при k ≤ 0.10 периоды 14/21/28 почти неразличимы (TP 52 / near 4 при 0.05);
   период 7 шумнее. Падение нижней границы от train к test растёт с k (например, 14×0.10: 0.926 → 0.793).
5. **Эталон касания структурно благоприятствует k = 0** (он и есть «касание без допуска»), поэтому выбор k = 0 по
   этой метрике был бы искусственным — победитель **не выбран**.

## Точный недостаток данных

- **Нет независимой разметки near-miss.** Ни в `training/reference_patterns`, ни в `tests/fixtures/geometry_gold`,
  ни в архивах кандидатов нет отметок «засчитать/не засчитать как ретест». Нужна разметка владельцем
  **34 уникальных событий** из `near_miss_events.csv` (колонка `owner_label`: `RETEST` / `NOT_RETEST`); тогда
  precision каждого кандидата вычисляется точно, а не интервалом.
- **Исходный пример BRUSDT 1m 2026-10-18 недоступен как данные:** нет OHLC-снимка и линий владельца (только
  скриншоты в беседе). Использованы 6 реальных BRUSDT-кандидатов Scanner (7 границ, 1 near-miss событие) —
  это не пример владельца.
- **Triangle и горизонтальные уровни не покрыты:** Triangle-кандидаты в архиве только 1m (нет более детального
  эталона), горизонтальные/зеркальные уровни с as-of и последующими свечами в архивах отсутствуют; Gold-фикстуры
  обрываются на моменте решения (у RSRUSDT — 3 свечи после).
- **Отрицательных случаев почти нет:** NO_TOUCH = 1 из 63 (за 24 ч после голого пробоя клиновые линии почти
  всегда касаются). Для оценки ложных срабатываний без касания нужны независимые отрицательные уровни.
- **Объём:** 67 границ / 34 near-miss события; train/test по 33/34 — интервалы неопределённости широкие.

## Ограничения метода

- 5m-детекция; 1m-эталон доказывает только физическое касание (не суждение владельца). Внутри 1m-свечи порядок
  тиков неизвестен; неоднозначные 1m-касания исключены.
- Линия переведена из 1m-индексов в непрерывное время (значение в начале 1m-индекса); Robot использует одно
  значение на свечу — расхождение ≤ одного шага наклона.
- Окно наблюдения 24 ч и прогрев ATR 40 свечей — параметры эксперимента, не торговые правила.
- Отбор «пробой до вершины» — экспериментальное ограничение для клина; правило владельца о границе после вершины
  не определено.
