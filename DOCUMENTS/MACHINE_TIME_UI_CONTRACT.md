# Машина времени — действующий UI-контракт владельца

**Состояние требований: 10.11.2026.** Единый локальный интерфейс:
`research/local_replay_viewer/` + `terminal/frontend/src/replay/`.
Этот документ имеет приоритет над устаревшими UI-описаниями и
скриншотами H-017 / Simulator V2 / прежних релизов; текущие инструкции
владельца ещё приоритетнее. Это не разрешение на merge или deploy.

## Утверждённый интерфейс

1. График занимает **всю доступную ширину**. Правая панель
   **«События» удалена**; возвращать её или создавать дубль нельзя.
   Не удалять сами журналы/события SIMULATION: они необходимы плееру,
   исполнению, маркерам, воспроизведению и отчётам.
2. Компактный плеер расположен **в одной строке с M5/H1**:
   иконки `Пуск/Пауза`, `Шаг назад`, `Шаг вперёд`, `В начало`,
   затем **рабочий ползунок перемотки**, справа — **скорость**.
   Отдельного ползунка перемотки над графиком нет.
   Перемотка идёт по причинно закрытым свечам, отключает autoplay
   и не пересчитывает/не изменяет результаты робота.
3. Ввод периода — одна строка
   `XRPUSDT | 2026-09-11T00:00 | 2026-09-11T23:59`
   с `Вставить из буфера` и `Применить`. Начало/конец — UTC,
   конечная минута включена, выбранные параметры не подменяются.
4. Существующий ряд периода: **1 час / 1 день / 1 неделя**
   с составной кнопкой непосредственно **слева** от названия единицы:
   верхняя половина `+`, нижняя `−`; высота обеих половин вместе
   равна высоте соседней основной кнопки. Нажатие добавляет/вычитает
   выбранную длительность, не меняя начало прогона.
   Неположительная длительность запрещена; 90 суток — максимум.
   `+1 месяц` пока сохраняется отдельной кнопкой, месяц = 30 дней.
   Быстрый `3 месяца · 90 дней` сохраняется, пока не будет иной команды.
   Под кнопками видна точная продолжительность до минуты:
   `1 месяц 15 дней 7 часов 16 минут`.
5. Нижний дублирующий блок `Инструмент / С UTC /
   По UTC (не включительно)` убрать. Кнопку
   `Загрузить Bybit (без сделок)` перенести **вправо в верхнюю
   панель настройки периода**, не смешивая public GET с торговым запуском.
6. При запуске нового SIMULATION-прогона на выбранных тикере/периоде
   предыдущие свечи, маркеры и демоданные очищаются автоматически.
   Далее этот же график показывает реальные **проверенные свечи**
   одного выбранного тикера в последовательности времени, события
   исходных Scanner → Robot → VirtualExchange и их виртуальный PnL.
   Нельзя выдавать результат нового XRPUSDT вместе со старым
   `SYNTHETIC_DEMO`; отсутствие подтверждённой истории должно
   блокировать запуск без синтетической подмены.
7. Остальные элементы интерфейса оставлять без изменений,
   пока владелец отдельно не примет решение. Только SIMULATION,
   никакого PAPER/MAIN/LIVE и торговых ордеров на Bybit.

## Реализация и ворота приёмки

- **Внесено в PR #974 с этим изменением:** отсутствие правой
  панели «События» в DOM, одна широкая область графика,
  расположение ползунка между иконками и скоростью.
  Ранее уже реализованы ввод тикера/дат, прибавление периода,
  подпись продолжительности и пиктограммы плеера.
- **В коде, ещё без пользовательской приёмки:** при запуске Wedge
  SIMULATION прежний график немедленно скрывается, после ответа
  автоматически подставляются закрытые M5-свечи из **того же**
  проверенного M1-прогона и фактические виртуальные исполнения,
  затем штатный плеер начинает воспроизведение с нуля. Второго
  Scanner/Robot и повторного анализа для рисунка нет. Неполные
  M5-группы не выдаются за завершённые; при отсутствии M5 запуск
  блокируется с сообщением вместо синтетической подмены.
- **НЕ реализовано / владелец ещё не принимал:** составные
  `+/−` у часа/дня/недели, удаление нижнего дубликата,
  перенос кнопки Bybit. Сам график также ждёт приёмки на ПК.
- Регрессионный барьер: `terminal/frontend/e2e/local-replay-browser.mjs`
  обязан проверять отсутствие `.replay-events` и заголовка
  `События`, **вложение** `.replay-seek` в
  `.replay-playback-controls`, порядок «иконки → ползунок →
  скорость», работоспособность ползунка. Для следующих функций
  вводить такие же проверки вместе с реализацией; без них
  нельзя считать ворота закрытыми.
- CI подтверждает кодовую регрессию, но **не заменяет**
  пользовательскую браузерную приёмку на ПК. Старые README
  и исторические архитектурные заметки не являются UI-эталоном.
