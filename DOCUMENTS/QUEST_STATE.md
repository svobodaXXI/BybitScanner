## 🎯 Активный квест

### Рейд «Г-образные врата»

**Приоритет:** №1  
**Статус:** АКТИВЕН  
**Цель:** подключить L-shape к PAPER Robot через существующий общий lifecycle и
дать владельцу настоящую кнопку «🤖 Робот».

**Главный босс:** «Врата допуска»  
Техническая причина: общий `robot_admission` / state-machine сейчас не
поддерживает L-shape как исполняемый Robot pattern, а L-shape Telegram sender
намеренно создаёт наблюдение без Robot candidate.

**Этапы рейда:**

- [ ] определить минимальный L-shape -> durable candidate contract;
- [ ] переиспользовать общий Robot lifecycle без второго execution engine;
- [ ] сохранить L-shape-специфичные 0.8% potential, RR >= 2:1 и frozen STOP/TAKE;
- [ ] подключить реальный Telegram «🤖 Робот» к настоящему candidate;
- [ ] пройти минимальную обязательную PAPER-проверку;
- [ ] только после доказанного completion начислить награду.

**Награда:** 50 XP  
**Ачивка-кандидат:** «Новый монстр, старый движок»

## Очередь после активного квеста

### 2. 👹 Босс «Кривой первый импульс»

Правило владельца:

- отчётливая встречная коррекционная волна завершает первый импульс;
- допускаются только 1–2 небольшие встречные свечи как пауза;

причина действительно общая.

## Правило автоматического восстановления

При первом BybitScanner-сообщении нового ChatGPT-чата:

1. загрузить `AGENTS.md`;
2. восстановить минимальный task-scoped контекст;
3. прочитать этот файл;
4. сверить его с верхним текущим priority index в `DOCUMENTS/BACKLOG.md`;
5. если пользователь в новом чате сразу даёт новый приоритет — он побеждает;
6. продолжить уже в русском игровом режиме;
7. не просить пользователя вручную переносить этот контекст.

документационном checkpoint, а не следовать устаревшему квесту.
