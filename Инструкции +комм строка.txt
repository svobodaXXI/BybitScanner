Если на другом Windows-компьютере уже находится актуальная папка C:\BybitScanner со всеми файлами проекта и config.py, то запуск практически элементарный.

Начиная буквально с нуля:

Нажимаешь Пуск → вводишь PowerShell → открываешь Windows PowerShell.
Переходишь в проект:
cd C:\BybitScanner
Если это новый компьютер, сначала проверяешь Python:
python --version

Нам нужен установленный Python. Сейчас проект разрабатывается на Python 3.12.

При первом запуске на новом ПК устанавливаешь зависимости:
python -m pip install -r requirements.txt

Это делается один раз на новом компьютере.

Запускаешь Telegram Review listener, чтобы работали кнопки. Для него лучше открыть второе окно PowerShell и выполнить:
cd C:\BybitScanner
python telegram_review.py

Это окно оставляешь открытым.

В первом PowerShell запускаешь сам сканер:
cd C:\BybitScanner
python main.py

И всё. Пойдёт полный прогон.
