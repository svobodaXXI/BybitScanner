# BybitScanner

Автоматический аналитический сканер торговых структур для рынка Bybit USDT Perpetual Futures.

Проект предназначен для:

- получения рыночных данных Bybit;
- поиска графических структур;
- анализа геометрии цены;
- оценки качества структуры;
- подтверждения сигнала;
- формирования уведомлений;
- отправки сигналов в Telegram.

BybitScanner не является торговым роботом.

Он:

- не открывает сделки;
- не управляет капиталом;
- не принимает финансовые решения.

Market Data
↓
Geometry
↓
Pattern Detection
↓
Confirmation
↓
Score / Quality
↓
Signal
↓
Notification
