# Simulator 2.0 — изолированный исследовательский подпроект

> **ОБЯЗАТЕЛЬНАЯ СТЫКОВКА:** в будущем объединить с текущей «Машиной времени» H-017 **в один симулятор**, не клонировать её движок. [Решение и границы](../../DOCUMENTS/SIMULATOR_V2_INTEGRATION_NOTE_20261109.md) · [основная спецификация, PR #960](https://github.com/svobodaXXI/BybitScanner/pull/960).

**Пока:** работаем только здесь, на отдельной ветке, не меняем `research/local_replay_viewer/` и файлы H-017. GitHub-merge и установка в ПК/VPS запрещены без соответствующей приёмки/разрешения.

Следующий независимый компонент — `virtual_account.py`: **внутренний виртуальный счёт** с явно задаваемым депозитом; он принимает только подтверждённые `VirtualFill(namespace="SIMULATION")` и вычисляет среднюю цену, количество, реализованный PnL, комиссии, нереализованный PnL и equity по заданной закрытой рыночной цене. Историческая проекция не меняет журнал. Дубли fills, чужой run/symbol, неизвестные комиссии, превышение виртуального баланса и неявный переворот позиции отклоняются. Здесь **нет** метода создать/отправить реальный либо виртуальный ордер: фактическая моделирующая биржа будет отдельным адаптером, без дублирования торговой логики Robot. Текущий баланс **не объявляется свободной маржой**: плечо, обеспечение, ликвидация и доступный объём пока не моделируются.

Первая реализуемая часть — `timeline.py`: событийный источник **закрытых M1**, вычисленные закрытые M5/H1, строгий шаг Scanner→Robot→Exchange только при переданных обработчиках и журнал `SIMULATION` для read-only rewind. Это **не** новый детектор, Robot, торговый исполнитель или пользовательский интерфейс. По умолчанию торговых callbacks нет, а реальные Scanner/Robot не импортируются.

Переиспользуем `research.historical_market_replay.Candle` и `research.historical_candle_feed.ClosedHigherTimeframeFeed`. Любые будущие интеграции реальных Scanner/Robot должны иметь изолированное состояние, виртуальное время, идемпотентность, fail-closed barrier и отсутствие доступа к настоящим биржевым ордерам/PAPER.

Прицельный тест (после включения ветки в поддерживаемый тестовый workspace): `python -m unittest discover -s tests -p test_simulator_v2_timeline.py`. Он не требует сети, торговых ключей или служб.

**Не объявлять полноценной симуляцией:** есть только изолированный учёт переданных виртуальных fills, но пока нет подключённых настоящих стратегий, виртуального исполнителя, загрузки месячной истории и UI.
