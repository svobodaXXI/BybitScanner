МАШИНА ВРЕМЕНИ — ЛОКАЛЬНЫЙ ПРОСМОТР ИСТОРИИ BYBIT

1. Распакуйте весь архив в отдельную папку на ПК или ноутбуке.
2. Запустите START_LOCAL.cmd двойным щелчком.
3. Откроется браузер с локальным окном симуляции.
4. Выберите BTCUSDT (или иной USDT linear-инструмент), даты UTC (не больше 7 дней)
   и нажмите «Загрузить Bybit (без сделок)».
5. Воспроизводите свечи с нужной скоростью. Для остановки закройте окно запуска.

Нужен установленный Python 3.11+ и доступ к публичному api.bybit.com.
Node.js, PAPER-аккаунт, VPS и ключи Bybit НЕ нужны.
История приходит только через публичный GET, всё остаётся в памяти процесса.
SIMULATION не записывает сделки или отчёты PAPER и не посылает ордера.
Жёлтые и синие линии — НЕПРОВЕРЕННЫЕ геометрические кандидаты, а не сигналы.
Пока это визуализатор истории и тестовой геометрии, не торгующий робот.

Запуск только локальный: 127.0.0.1, случайный порт. Никаких сервисов VPS.
Если общедоступный API Bybit недоступен в вашей сети, история не подменяется
вымышленными свечами; получите явную ошибку загрузки.
