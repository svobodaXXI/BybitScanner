МАШИНА ВРЕМЕНИ — ЛОКАЛЬНЫЙ ПРОСМОТР ИСТОРИИ BYBIT

1. Распакуйте проверенный Windows ZIP в отдельную папку.
2. Запустите START_LOCAL.cmd двойным щелчком.
3. Если в папке есть real-h1-august.json, браузер автоматически загрузит
   проверенную публичную историю GRASSUSDT (20–26.08.2026) БЕЗ интернета.
   Воспроизведение начинается с нулевой позиции; используйте «Пуск»,
   «Шаг вперёд» или ползунок скорости рядом с M5/H1.
   Для возврата к синтетическому демо нажмите «Пример».
4. Для другого USDT linear-инструмента выберите символ/даты UTC
   (не больше 7 дней) и нажмите «Загрузить Bybit (без сделок)».
   Можно также импортировать иной совместимый JSON.
5. Для остановки закройте окно запуска.

Нужен установленный Python 3.11+. Node.js, ключи Bybit, PAPER-аккаунт
и VPS не нужны. Интернет требуется ТОЛЬКО при ручной загрузке других
публичных свечей через api.bybit.com. Встроенный архив читается лишь
из своей папки через loopback 127.0.0.1 без приватных запросов.
SIMULATION не записывает сделки или отчёты PAPER и не посылает ордера.
Жёлтые/синие линии — НЕПРОВЕРЕННЫЕ исследовательские кандидаты.
Новая панель «Стратегии и период» позволяет выбрать часы и минуты UTC,
пресеты 1/7/30/90 дней, Mirror/другие паттерны и режим «Только клинья».
Торговый запуск пока поддерживает ТОЛЬКО восходящие/нисходящие клинья:
комплекс Mirror и «Все стратегии» ещё не подключены к виртуальной торговле.

Виртуальные сделки не используют биржевой аккаунт. Чтобы кнопка
«Запустить клинья · SIMULATION» стала доступна, требуются:
- каталог simulator-v2-data/m1-cache с уже проверенными M1, агрегированными
  из публичных дневных торговых архивов Bybit;
- simulator-v2-data/manifest.json с SHA-256 всех исходных торговых дней
  и M1 (формат SIMULATOR_V2_PUBLIC_TRADES_DERIVED_M1_RANGE_V1);
- simulator-v2-data/wedge-risk.json: отдельный локальный JSON с ключами
  «scanner» и «risk», описанными в research/simulator_v2/wedge_cli.py.
  Профиль должен содержать документированные условия инструмента:
  tick_size, contracts_per_working_volume, quantity_step,
  minimum_quantity, max_notional_usdt, max_risk_usdt,
  entry_fee_rate, exit_fee_rate, terms_source.
  Эти значения НЕ подставляются автоматически и НЕ берутся из PAPER.

Когда оба файла подготовлены, START_LOCAL.cmd при Python 3.11 создаёт
отдельное .wedge-python в папке приложения и устанавливает pandas/numpy
ТОЛЬКО из вложенного offline python-wheels. Глобальный Python и другие
проекты не изменяются. Без архива/профиля обычный просмотрщик запускается
как прежде, а кнопка виртуального прогона недоступна.

Отчёт — только исследовательская OHLC-модель: Net PnL, комиссии,
просадка, STOP/TAKE. Он не подтверждает реальное биржевое исполнение
и не является доказательством прибыльности стратегии до прогона
на настоящих подтверждённых данных. Отдельного приложения и VPS нет.
