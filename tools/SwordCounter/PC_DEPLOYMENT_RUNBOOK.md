## Что должна делать утилита

Независимое компактное Windows-окно `SwordCounter` со значком скрещённых мечей слева от заголовка (без символов ⚔ в тексте заголовка), поверх остальных окон; доступно сворачивание и закрытие. Наверху `1 РО = N USDT`; далее «Свободно» (зелёное число) и «Задействовано» (красное число). По умолчанию 20 мечей (меняется через шестерёнку). 1 РО = Account Equity (`totalEquity`, `GET /v5/account/wallet-balance`, UNIFIED, включая нереализованный PnL) / количество мечей, `ROUND_HALF_UP` до целого USDT, пересчёт каждые 10 секунд; ручной цены РО нет. Пока Equity неизвестен — `1 РО = — USDT` и без чисел; Equity ≤ 0 или РО, округлённый до 0, — «Недоступно». Настройки в `%APPDATA%\SwordCounter\settings.json`. Обновление с Bybit каждые 10 секунд. Если соединение, данные или цена входа недоступны, не выдавать устаревшие/ложные числа.

**Правильная формула (принято владельцем и проверено на LIVE):**
- Объём каждой открытой USDT-позиции = `size × avgPrice` — номинал по **цене входа**, а не текущая рыночная цена.
- Общий занятый объём = сумма `size × avgPrice` по всем позициям отдельного ручного аккаунта.
- Задействовано = `ceil(общий объём / цена 1 РО)`; свободно = `max(0, общее количество − задействовано)`.
- Считать точно через `Decimal`; не использовать для этой цели ни `positionIM`, ни `positionValue`, ни деление на плечо.
- При открытой USDC-позиции или недостоверных данных — «Недоступно», без молчаливого смешивания валют.

**Подтверждённый снимок LIVE, не постоянные числа:** SENTUSDT 4,79178 + VELVETUSDT 3,64 + XNYUSDT 4,9744 + LYNUSDT 4,97852 = **18,3847 USDT** → **4 задействовано / 16 свободно** при 20×5 USDT. Два независимых чтения с интервалом 10 секунд совпали. Это пример проверки, а не ожидаемый результат навсегда: открытые позиции могут измениться.

## Доступ и границы безопасности

SwordCounter использует **собственный** HMAC API-ключ Bybit с правами **Read-Only**. В шестерёнке раздел «Подключение Bybit»: видимый API Key, API Secret с «Показать/Скрыть», «Проверить подключение», затем «Сохранить ключ». Сохранение только после `readOnly=1` через `GET /v5/user/query-api` и успешного чтения `GET /v5/position/list`. Ключ хранится в **Windows Credential Manager**, Generic Credential `SwordCounter/BybitReadOnly`, отдельно в профиле **каждого** пользователя Windows; в JSON, ярлыки, Git и лог его не писать. Не использовать ключи Robot или Scanner. Окно не должно брать ключ из переменных окружения.

На другом ПК безопасно ввести отдельный разрешённый Read-Only ключ через настройки SwordCounter; проверить применимость IP-ограничения ключа к **тому ПК**. **Не переносить** Credential Manager blobs, DPAPI-профили, секреты или файлы с токенами копированием; ключ, работающий на одном ПК, не гарантированно доступен на другом.

Торговых команд SwordCounter не выполняет; Scanner, Robot, Backend, Autopilot, PAPER DB, LIVE-торговый runtime не запускать и не модифицировать при его установке.

## Перенос на второй ПК (пошаговая проверка, без предположений о путях)

1. Уточнить, что это нужная Windows-машина и что на ней реально установлены MetaScalp и Python/venv; **не копировать слепо** пути `C:\Users\SVOBODA21` и `C:\BybitScanner`.
2. Получить **проверенную версию** SwordCounter из исходников GitHub: ветка `feat/sword-counter-s5-keys`, коммит `c6fa0d2` или более новая версия только после отдельной приёмки. Пока стек PR не слит, брать код из этой ветки, не из `main`. Переносить только SwordCounter и необходимые Python package markers; не запускать/не переносить торговый runtime.
3. Установить приложение в **реальный** `%LOCALAPPDATA%\SwordCounter\app` нужного пользователя, видимый Проводнику. Проверить наличие `tools\SwordCounter\launcher.py`, `app.py`, `swords.ico`, модуля ключей и `VERSION.txt`; проверить импорт `tools.SwordCounter` в выбранном Python. Обеспечить доступные `tkinter` и зависимости для read-only запроса; использовать подходящий Python/venv этого ПК.
4. Проверить фактический путь `MetaScalp.exe` и его параметры/рабочую папку, а также `pythonw.exe`; подготовить `MetaScalp + Мечи.lnk` с `-m tools.SwordCounter.launcher` и рабочей папкой установленного SwordCounter. **Не перезаписывать без резервной копии.** Отдельно проверить ярлыки рабочего стола и закреплённые на панели задач.
5. В окне SwordCounter через ⚙ ввести Read-Only API Key и Secret на **этом** ПК, нажать «Проверить подключение» и «Сохранить ключ». Не пересылать секреты в чат. Перепроверить права и IP-ограничения.
6. Закрыть работающий SwordCounter, один раз запустить общий ярлык из **Проводника**; убедиться, что MetaScalp и SwordCounter открылись, окно показывает свежие числа, а не «Нет соединения». Второй запуск ярлыка **не должен создавать дубликаты**. При ошибке проверить путь процесса, реальность папки установки, закреплённый ярлык и наличие Credential Manager записи **до** изменения кода.
7. Сделать две read-only сверки с Bybit через 10 секунд: сумма `size × avgPrice`, `ceil(sum / RO)`, свободные мечи. Сопоставить с GUI и MetaBroker по номиналу **по цене входа**. Сохранять только отчёт без секретов.
8. После PASS оставить рабочие ярлыки; резервные и старые worktree не удалять до явного разрешения владельца. Никакого автоматического merge.

## Критерий приёмки на втором ПК

**PASS** только когда **общий ярлык из обычной Windows-сессии** запускает MetaScalp + один экземпляр SwordCounter, с действительным Read-Only ключом и совпадающими фактическими числами по входной стоимости позиций; проверены оба ярлыка (если есть TaskBar pin). Offline-тесты, dry-run и «ключ настроен» без видимых цифр **не равны PASS**.

## История типовых дефектов

- Ошибочный подсчёт по `positionIM` (~1,91 USDT вместо номинала ~19 USDT); затем по `positionValue` (двигался вместе с mark price). **Окончательно: `size × avgPrice`.**
- Строгий regex для ключа и скрытая вставка в консоли мешали диагностике `10003`; практическое решение — **видимые поля и проверка API в ⚙**, ключ не пересылать.
- Старый worktree S4/закреплённый ярлык + виртуализированный `LocalAppData` → устаревший код и «Нет соединения».
- Стандартное перо Tkinter заменено иконкой `swords.ico`; финальный title — **`SwordCounter`**, без ⚔ в тексте.
