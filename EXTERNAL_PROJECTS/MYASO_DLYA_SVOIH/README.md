## Рабочая граница
Цифры и пропорции контента — стартовые гипотезы, не подтверждённые охваты. Не публиковать неподтверждённые обещания («100% без добавок», «гарантированная безопасность», доставка и оплата), пока они не проверены у производителя и на соответствие требованиям.
